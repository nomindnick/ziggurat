# opponents/ — behavioral profiles

One file per league team, named after the *team* (not the person). Lighthearted
competitive notes about fantasy play only — lineup-setting diligence, waiver
activity, bye-week negligence, points-chasing, roster hoarding, trade
receptivity — never personal details, even locally.

Suggested profile fields:

```markdown
# <Team Name>
- Lineup diligence: (sets weekly? starts players on bye/OUT?)
- Waiver behavior: (active? chases last week's points?)
- Trade posture: (receptive? initiated any?)
- Dated observations:
  - 2026-09-XX: ...
```
