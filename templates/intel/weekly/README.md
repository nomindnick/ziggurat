# weekly/ — decision journal & retros

One file per NFL week once the season starts: decisions made (with reasoning
and alternatives), plus the Monday retro grading each decision on **process,
not outcome** (correct-but-unlucky logs as variance, not error).

Journal and decision-log templates land with the operating cadence (item 3.7).
Every ~4 weeks, journals get distilled into `../rest_of_season_priors.md`
(scheduled memory compaction — see CLAUDE.md).
