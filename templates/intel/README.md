# intel/ — the memory & judgment layer

Markdown memory for the season: opponent behavioral profiles, player watch
notes, the weekly decision journal, spike/research findings, and the
heuristics promotion ladder.

**This tree is gitignored — league-private, never committed.** The public repo
shows the method; this directory is the intelligence. On a fresh clone, run
`ziggurat intel init` to recreate the skeleton from `templates/intel/`.

- `opponents/` — per-team tendencies (game-related notes only, even locally)
- `weekly/` — decision journal + Monday retros (templates land in item 3.7)
- `research/` — spike findings and distilled research holdings
- `heuristics.md` — observation → hypothesis → rule ladder
